# Third-party art credits

Every asset dropped into `Assets/Art/Imported/{Props,Machines,Characters}/` is recorded here: what it
is, where it came from, and under what licence. CC-BY and several of the other permissive licences
this project expects to use require attribution *in the shipped product*, not only in this
repository, so this file is the source the in-game credits screen is generated from — see
`Residue/Content/Rebuild Credits` and `Assets/Scripts/Net/UI/CreditsPanel.cs`. Add an entry here in
the same commit that adds the asset, then run the rebuild so the credits screen picks it up; a second,
hand-typed copy is the one that drifts.

## Format

- **Asset name** — source (site/author), licence, any attribution line the licence requires verbatim.
